# Othello (オセロ) 仕様書

## ゲームルール

- 8×8 ボード、初期配置は中央の 4 マスに交互に石。
- `player 0` = 黒(先手・盤面値 `+1`)、`player 1` = 白(`-1`)。
- 標準ルール:相手の石を挟む手のみ合法。合法手が無い場合は **パス**。両者連続パスで終局。
- 終局時、石の数が多い方の勝ち。同数なら引き分け。

## 行動空間

- 整数 `0..63`(`row * 8 + col`)
- `64` = **パス**(合法手が一つも無い時のみ)
- 違法手は即敗北。

## 観測

- `array`: shape `(2, 8, 8)` の `float32`、canonical。
  - チャンネル0: 自分の石、チャンネル1: 相手の石。
- `state_key`: 64文字。`X` = 自分、`O` = 相手、`.` = 空。

## モデル入出力

### CSV
- ヘッダ: `state_key,action,value`。

### ONNX
- 入力: `(1, 2, 8, 8)` float32。
- 出力: `(1, 65)` float32(64 着手 + パス)。
- 違法手はマスクされてから argmax。

# Connect Four (コネクトフォー) 仕様書

## ゲームルール

- 6行 × 7列。プレイヤーは列を選ぶと、その列の最下段の空きマスに石が落ちる。
- 縦・横・斜めいずれかに 4つ並べた方の勝ち。
- 全マス埋まったら引き分け。
- `player 0` = 先手(`X`、`+1`)、`player 1` = 後手(`O`、`-1`)。

## 行動空間

- 整数 `0..6`(列インデックス)。
- 列が満杯なら違法手。違法手は即敗北。

## 観測

- `array`: shape `(2, 6, 7)` の `float32`、canonical(現プレイヤー視点)。
  - row 0 が **最下段**(物理的にボードの一番下)。
- `state_key`: 42文字。**上の行から** 書き出した文字列(表示順)。`X`/`O`/`.`。

## モデル入出力

### CSV
- ヘッダ: `state_key,action,value`。

### ONNX
- 入力: `(1, 2, 6, 7)` float32。
- 出力: `(1, 7)` float32。
